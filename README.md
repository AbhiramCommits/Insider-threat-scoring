# Insider Threat Scoring

Machine learning pipeline for detecting insider threats from behavioural telemetry data. Trains classifiers on aggregated user-level features, explains predictions with SHAP, and exports human-readable risk scores.

## Project Overview

The pipeline ingests daily user activity logs (logins, USB events, email, file access, VPN, failed logins), aggregates them into **53 engineered features** per user, and trains a supervised model to predict insider-threat risk. All steps are accessible via a single CLI entry point.

```
                 daily telemetry
                       │
           ┌───────────▼───────────┐
           │  feature_engineering   │  → 53 features / user
           └───────────┬───────────┘
                       │
     ┌─────────────────┼─────────────────┐
     ▼                 ▼                 ▼
  train            score             explain
(RF/XGB/LR)    (risk_scores.csv)   (SHAP plots + report)
```

## Dataset

**`data/synthetic_cert.csv`** — a realistic, CERT-style synthetic dataset generated by `data/generate_synthetic.py`.

| Property | Value |
|----------|-------|
| Users | 2,000 |
| Days | 90 |
| Total rows | 180,000 |
| Threat-positive rate | 5.0 % (row level) |
| Raw columns | `user_id`, `date`, `login_hour`, `is_weekend`, `after_hours_login`, `usb_events`, `email_sent_count`, `email_external_ratio`, `file_access_count`, `failed_logins`, `vpn_usage`, `label` |

Threat rows are injected with elevated after-hours activity, USB events, external email ratios, file-access spikes, failed logins, and VPN usage — mirroring real-world insider-threat patterns from the CERT dataset.

## Feature Engineering

Raw daily telemetry is aggregated per user into **53 features** across 10 categories (plus the `label` target). The full catalogue is in [`features/feature_catalog.md`](features/feature_catalog.md).

| Category | Count | Examples |
|----------|-------|----------|
| Temporal | 5 | `after_hours_ratio`, `weekend_ratio`, `login_hour_variance` |
| Time Distribution | 5 | `login_hour_std`, `login_hour_skew` |
| Time Bucket | 4 | `morning_ratio`, `evening_ratio`, `night_ratio` |
| Activity – USB | 5 | `usb_event_total`, `usb_event_spike`, `usb_days_ratio` |
| Activity – Email | 7 | `email_volume_total`, `external_email_ratio_mean` |
| Activity – File | 6 | `file_access_anomaly_score`, `file_access_cv` |
| Activity – Access | 4 | `failed_login_total`, `failed_login_ratio` |
| Activity – VPN | 2 | `vpn_usage_ratio`, `vpn_usage_total` |
| Deviation (7d rolling) | 9 | `login_hour_deviation_count`, `email_sent_count_max_deviation` |
| Interaction / Composite | 6 | `usb_after_hours_total`, `high_risk_day_count`, `avg_risk_flags` |

Key functions in `src/feature_engineering.py`:
- `build_temporal_features()` — schedule patterns
- `build_activity_features()` — volumetric & spike metrics
- `build_deviation_features()` — 7-day rolling z-score deviations
- `aggregate_user_features()` — merges all → 1 row per user

## Model Comparison

Three classifiers trained with **SMOTE-augmented stratified 5-fold CV** (`imblearn.pipeline.Pipeline`):

| Model | CV F1 | CV ROC-AUC | Test F1 | Test ROC-AUC |
|-------|-------|------------|---------|--------------|
| Logistic Regression | 0.9994 ± 0.0008 | 0.9994 | 0.9987 | 0.9823 |
| Random Forest | 0.9994 ± 0.0008 | 1.0000 | 0.9987 | 1.0000 |
| XGBoost | 0.9994 ± 0.0008 | 1.0000 | 0.9987 | 0.9981 |

The best model (by test F1) is saved to `outputs/best_model.pkl`. Full metrics in `outputs/metrics.json`.

> **Note:** Scores are near-perfect because the synthetic threat signal (after-hours activity, USB spikes, file-access anomalies) creates strong class separability at the user level. Real-world CERT data would show lower, more realistic scores.

## Risk Scoring

Each user receives a **0–100 risk score** with a categorical level:

| Range | Risk Level |
|-------|------------|
| 0 – 24 | Low |
| 25 – 49 | Medium |
| 50 – 74 | High |
| 75 – 100 | Critical |

## Setup

```bash
# Clone and enter the project
cd insider-threat-scoring

# Create a virtual environment (recommended)
python -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Generate the synthetic dataset
python data/generate_synthetic.py
```

## Usage

### Full pipeline via `main.py`

```bash
# Step 1 — Train models (saves best_model.pkl + metrics.json)
python main.py --mode train

# Step 2 — Score all users (generates risk_scores.csv)
python main.py --mode score

# Step 3 — Generate SHAP explanations (plots + report)
python main.py --mode explain

# Custom paths
python main.py --data path/to/data.csv --output path/to/out --mode train
```

### CLI flags

| Flag | Default | Description |
|------|---------|-------------|
| `--data` | `data/synthetic_cert.csv` | Path to input CSV |
| `--mode` | *(required)* | `train`, `score`, or `explain` |
| `--output` | `outputs` | Directory for output artefacts |

### Jupyter Notebooks

```bash
jupyter notebook notebooks/
```

Run in order: `01_Feature_Engineering` → `02_EDA` → `03_Modeling` → `04_SHAP_Explainability`.
